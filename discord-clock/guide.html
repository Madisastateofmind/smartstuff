Launch the clock in a call

  1. Open World Clock Together’s Discord app listing and follow the prompts to add the app. The listing becomes available once Discord Discovery is enabled.
  2. Join a server voice channel, or start a DM or group DM call.
  3. While connected to the call, click or tap the Activities button.
  4. Find World Clock Together and select Launch.
  5. Have your friends join the Activity, then use the timezone dropdown to compare times!

The dropdown uses fixed UTC offsets. Those selections do not automatically adjust for daylight saving time. The named London, Eastern and Pacific clocks adjust using your browser’s time-zone data.

🔊 Optional gentle clock ticking

Ticking audio comes from a separate voice bot. Installing the clock Activity does not automatically add ticking to your server.

To silence ticking just for yourself, mute Noxyr or lower its user volume.

Set up ticking in your own server

  1. Add Noxyr to your server.
  2. For this setup, allow View Channels, Send Messages, Embed Links, Connect, and Speak in the relevant channels. You do not need to grant Administrator or moderation permissions.
  3. Create a text channel such as bot-testing where you can write commands. This channel can be private.
  4. If it is private, add Noxyr’s account or role to the channel’s permissions. Allow View Channel, Send Messages, and Embed Links. You can also allow Read Message History so it can read earlier messages; that permission alone is not required to reply to a new slash command.
  5. Create or choose a voice channel for the clock, such as World Clock Together.
  6. On desktop, right-click that voice channel and choose Edit Channel → Permissions. On mobile, open the channel’s settings. Add Noxyr’s account or role and allow View Channel, Connect, and Speak.
  7. Join the voice channel you just set up. Stay connected while you configure playback so Noxyr knows which voice channel to join.
  8. While still connected to voice, open your bot-testing text channel. Run /play and enter this audio link: https://madisastateofmind.github.io/smartstuff/discord-clock/wallclock.wav
  9. While the recording is playing, run /loop and choose the option to repeat the current track. Do this quickly—the audio is only about four seconds long! If it ends before you finish, run /play again and retry.
  10. Once it is looping, run /playlist save and name the playlist Clock ticking.
  11. Run /play-24-7 and select the saved Clock ticking playlist. This sets the playlist to repeat in 24/7 mode.
  12. Use /volume to set a gentle listening level. 25% is a starting point—adjust it to suit your ears.
  13. In the same voice call, open Activities → World Clock Together → Launch to show the clocks alongside the ticking.

Listening and stopping

Only people connected to the voice channel hear the ticking. You do not need to have the clock Activity open to hear it.

When you hang up, you stop hearing it. The bot’s saved playlist remains set to 24/7 mode, so your computer does not need to stay on.

Run /stop to stop playback for everyone and make the bot leave the call.

The clock Activity and ticking bot can run together in the same server voice channel. These voice-bot instructions are for servers, not DM calls. Noxyr is an independent service; its commands and availability may change. See Noxyr’s music guide for current help.

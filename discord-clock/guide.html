⏰ World Clock Together

A free world clock to help friends compare times across time zones.

Set up and launch the clock

  1. Open World Clock Together’s Discord app listing and follow the prompts to add the app. The listing becomes available once Discord Discovery is enabled.

    If the link opens Discord in your browser, sign in there to add the app. Then return to the Discord desktop or mobile app to launch it.

  2. Open the server text channel where you want to use the clock. You can create a dedicated channel such as world-clock, or use an existing one. A voice call is not required.
  3. Open Discord’s App Launcher in the channel, find World Clock Together, and choose Launch. If Discord offers the app’s Launch command while you type /, you can select that instead.
  4. The clock opens inside Discord. Use the timezone dropdown to compare times with your local time.
  5. Friends with access to the channel can use the Activity’s invitation card to join. You can pin that card to make it easier to find later.

The dropdown uses fixed UTC offsets. Those selections do not automatically adjust for daylight saving time. The named London, Eastern and Pacific clocks adjust using your browser’s time-zone data.

Use the clock in a call

If you prefer, join a server voice channel or start a DM or group DM call. Open the call’s Activities / App Launcher button, select World Clock Together, and choose Launch.

Open it again later

The app remains installed when an Activity session ends. Launch it again through the App Launcher, or use Play on its invitation card if Discord offers it. You do not need to install the app again.

Discord may keep the clock in a floating picture-in-picture window while you browse other channels. Click the window to return to the larger Activity view. The clock is opened when you launch it; it is not a permanently running participant in a channel.

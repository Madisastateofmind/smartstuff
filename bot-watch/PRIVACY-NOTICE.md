# Proposed WCT privacy-policy addition
Publish this only when collection is activated; it is not a statement that tracking is live today.

## Anonymous usage statistics
World Clock Together sends a usage signal when the clock opens and once per minute while its page is visible.
Signals contain the app name, whether it opened as a Discord Activity or website, and a random session identifier created for that page load.
The operator does not collect Discord usernames, messages, server identifiers or account identities for these statistics.
No visitor tracking cookies or persistent visitor identifiers are used.
Temporary session records expire after 24 hours without a signal. Aggregate daily launch counts are retained to understand use over time.
The service is hosted on Cloudflare; Cloudflare may process network addresses and other request information to provide and secure its service.
Statistics are visible only to the operator through a private dashboard protected by GitHub sign-in.
GitHub processes the operator's authentication under its own privacy policy.
